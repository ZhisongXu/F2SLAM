## Overview

F² SLAM turns feed-forward multi-view geometry into persistent measurements
inside a dense SLAM factor graph. A high-frequency stream preserves local
tracking and connectivity, while a low-frequency Flow3r stream contributes
wider-context pose, depth, and correspondence evidence to the same bundle
adjustment problem.
